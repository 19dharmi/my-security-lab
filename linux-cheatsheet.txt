=== LINUX CHEATSHEET - Dharmi ===

FILE NAVIGATION
pwd          → where am I?
ls -la       → list all files with details
ls -a        → show hidden files
cd ~         → go home
cd ..        → go back one folder

FILE READING
cat file         → read a file
cat ./−file      → read file with dash in name
cat "spaced name" → read file with spaces

FINDING THINGS
find / -user x -group y -size 33c 2>/dev/null
grep "word" file → search inside file

DECODING
base64 -d    → decode base64
tr 'A-Za-z' 'N-ZA-Mn-za-m'  → ROT13
xxd -r       → hexdump to binary

COMPRESSION
file x       → what type is this file?
gunzip x.gz  → decompress gzip
bunzip2 x.bz2 → decompress bzip2
tar xf x     → extract tar

PIPING
cmd1 | cmd2        → feed output into next command
2>/dev/null        → throw errors away
sort | uniq -u     → find unique lines
